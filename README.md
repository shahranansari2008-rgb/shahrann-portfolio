# Shahran Ansari — Developer Portfolio

A modern, minimal personal portfolio website engineered for **Shahran Ansari**, Computer Science & Engineering student and aspiring software developer.

Built with **React.js**, **Tailwind CSS**, **Framer Motion**, **Lucide React**, and **Vite**.

---

## 🚀 Live Sections & Features

- **Hero Section**: Personal branding, taglines, availability indicator for internships, social links, and an interactive developer terminal widget.
- **About Me**: Academic affiliation at Allenhouse Institute of Technology (AKTU), problem-solving focus, and current technical learning areas.
- **Technical Skills**: Categorized skills (Programming, Web Development, Developer Tools) with interactive filters and hover states. No artificial rating bars.
- **Featured Projects**:
  - [Motivora](https://motivora.netlify.app/) — Motivational quotes app with REST API integration.
  - [Personal Profile Website](https://shahranprofile.netlify.app/) — Semantic HTML & modern CSS layout exploration.
  - [DevIdentity](https://devidentity.netlify.app/) — Interactive profile card component.
- **Education Timeline**: B.Tech CSE (2025–2029) with Semester SGPAs, Senior Secondary (MSVM), and Secondary School (Ambedkar Inter College).
- **Achievements & Certifications**: Google Skills "Introduction to Generative AI" learning badge, Smart India Hackathon (SIH) 2026 National-Level Stage participation.
- **Coding Profiles**: Direct links to GitHub, LeetCode, and LinkedIn.
- **Contact Section**: Direct mailto, phone, Kanpur location, and an interactive message form with transparent email client submission.

---

## 🛠️ Tech Stack

- **Framework**: [React 18](https://react.dev/)
- **Build Tool**: [Vite 6](https://vitejs.dev/)
- **Styling**: [Tailwind CSS 3](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Fonts**: Inter & JetBrains Mono

## 💻 Local Development

1. **Install dependencies:**
   ```bash
   npm install
   ```

2. **Start local development server:**
   ```bash
   npm run dev
   ```

3. **Build for production:**
   ```bash
   npm run build
   ```

4. **Preview production build:**
   ```bash
   npm run preview
   ```
